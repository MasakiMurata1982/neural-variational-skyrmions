# v の零点と電荷の変化（2026-10-01）

付録A.4 のモード(a) の段落に書いた再実行2本の記録。論文の表12 では
付録A.4 の行（2本）に当たる。

## 何をしたか

- 対象：記録で真空まで落ちたモード(a) の2本
  `free_B3_mlp_w64_d4_ep20000_s3_gelu` と `free_B4_mlp_w64_d4_ep20000_s9_gelu`
- 設定：`code/experiments/2026-08-31_free_uniform` の COMMON をそのまま
- `train_vzero.py` は配布物の `code/src/train.py` の写し。訓練ループの中身は変えず、各エポックの頭で
  格子 [-6,6]^3（121^3 点、間隔 0.1）の |v| の最小値・中央値・最小の位置を記録する
  （勾配なし、大域の乱数を使わない）。最初の2000エポックは毎エポック、以後20エポックごと。
  `_hist.npz` の `probe` 列が (epoch, min|v|, median|v|, x, y, z)。
- 実行は `python3 run_vzero.py g64_B3_s3,g64_B4_s9`（出力はこのフォルダの `runs_g64_B3_s3,g64_B4_s9/`）。最初に小さな run を1本走らせる（プロセスの最初の run が記録とずれるのを避けるため。`README.md` の4節）。
- 環境：RTX 3060、PyTorch 2.14.0+cu126。

## 結果

- **記録は再現しなかった。**エポック1〜2 は B, E が4桁一致、10エポックほどから分かれ、
  最後は目標のセクター（B=3.00001, E=4.0756, E2/E4=0.82／B=3.99999, E=4.6407, E2/E4=1.002）。
  記録はどちらも真空。
- 電荷の変化（訓練の B を21エポックの中央値で平滑化し、丸めた整数が変わったエポック）は
  最初の2000エポックで B=3 が15回、B=4 が2回。そのうち ±8 エポック以内に min|v| が
  その run の最初の2000エポックの中央値の 0.3 倍未満に下がったのは 14回と1回（計17回中15回）。
  外れたのは B=3 のエポック 1685（0.53倍）と B=4 のエポック 3（0.34倍、刷り込み直後）。
- 下がった値は 0.0178〜0.0862。最初の2000エポックでの min|v| の中央値は 0.38 と 0.12、格子全体の |v| の中央値は約2。
  比は 4.42〜16.0 分の1。論文（付録A.4）は、この範囲を外側に丸めて「0.01 から 0.09、4 から 17 分の1」と書いている。
- 上の回数と値は `code/analysis/summarize_vzero_probe.py` が、再実行2本の履歴（アーカイブ1）から出す。
